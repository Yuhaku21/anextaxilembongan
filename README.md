# AneX Taxi Lembongan

Landing page responsif untuk AneX Taxi Lembongan, dibuat dengan HTML, CSS, dan Bootstrap 5.

## Menjalankan secara lokal

Buka `index.html` di browser. Bootstrap dimuat dari jsDelivr, jadi koneksi internet diperlukan agar komponen navigasi dan styling Bootstrap tampil.

Saat halaman pertama kali dibuka, animasi loading akan tampil dan menutup otomatis setelah semua aset halaman selesai dimuat.

## Menyesuaikan tombol WhatsApp

Nomor WhatsApp bisnis `6281278250336` sudah diatur di `script.js` dalam format internasional tanpa tanda `+` atau spasi. Semua tautan booking dan chat WhatsApp menggunakan nomor ini. Untuk menggantinya, ubah nilai `WHATSAPP_NUMBER` di `script.js`.

Tombol WhatsApp mengambang di kanan bawah membuka panel chat. Pengunjung dapat menulis pesan lalu memilih **Kirim pesan** untuk meneruskan pesan ke WhatsApp.

Foto dan logo pada halaman menggunakan berkas yang tersedia di folder `asset`.
